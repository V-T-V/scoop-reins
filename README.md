# scoop-reins

Scoop bucket for [Reins](https://github.com/V-T-V/reins) — self-hosted zero-trust remote operations platform.

```powershell
scoop bucket add reins https://github.com/V-T-V/scoop-reins
scoop install reins
```

`reins-mcp`(MCP Server)与 agent/relay 请从 [Releases](https://github.com/V-T-V/reins/releases) 下载。
